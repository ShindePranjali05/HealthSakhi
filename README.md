# HealthSakhi 🌸

HealthSakhi is a women's health and wellness Android application designed to provide users with accessible information and support related to women's health.

## 📱 About the Project

HealthSakhi is an Android-based application developed to help women access health-related information and guidance through a simple and user-friendly interface.

The application focuses on topics such as:

- PCOS and PCOD awareness
- Breast cancer awareness
- Cervical cancer awareness
- Menstrual health
- Stress and anxiety relief
- Healthy diet and exercise recommendations
- Health-related chatbot support

## ✨ Features

- 🔐 User Login
- 🏠 User-friendly Dashboard
- 🩺 Women's Health Information
- 📅 Period Tracking
- 🤖 Health Chatbot
- 🥗 Diet Recommendations
- 🏃 Exercise Recommendations
- ⚙️ Settings

## 🛠️ Technologies Used

- Android Studio
- XML
- Kotlin / Java
- Git & GitHub
